## Shims / kit status

No stand-ins left. LabelTag, the lettered BackSoonTag and StickyNote landed in `shared/props` during the build and are
used directly. `scene11/shims.tsx` only holds NoteBreeze, a local wrapper that adds the breeze flutter (rotation about
the note's adhesive edge) and the pen jolt OUTSIDE the shared StickyNote (the shared prop has slap / strike / curl but
no flutter). If the props lane adds `flutterAt` / `joltAt` to StickyNote, drop the wrapper.
