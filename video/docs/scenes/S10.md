  - `sign` -> `Stoops` + `Plaques` + the A-frame node + the flying tags, `near` -> + Pip, `foreground` -> + `BottomCrowd`.
- **Props (shared)**: `SunPie`, `SupportTag` (landed, flying, in the hand, the far wave), `LabelTag`, `FixSign` (THE

  post over the wheel), `MakersCart` (pusher, size 100: the maker 143 px tall, the door-height eye level's person
