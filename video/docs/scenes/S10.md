## How it uses the kit

- **Set `OldQuarter`** (sets lane, v3 API): `noticeSign` slot (L13 = shared `LabelTag kind="sign" frame={false}` on
  the local `SandwichBoard`), `cart` slot (our cart), `furniture="bike"`, `people={false}`, and the railing, tree and

  - `second` -> local `SecondRow`; `sites` -> local `Sites` (no stoops, no plaques) + the gap walker (popping with siteR),
  - `sign` -> `Stoops` + `Plaques` + the A-frame node + the flying tags, `near` -> + Pip, `foreground` -> + `BottomCrowd`.
- **Props (shared)**: `SunPie`, `SupportTag` (landed + flying), `LabelTag`, `FixSign` (was the local CartSign shim),
  `MakersCart` (pusher), `ElephantEmblem`, `ElephantPlaque` (far plates), `Bit`, `Cobweb`, `BrowserChrome` (`content`,
  ring slot reserved), `Citizen`, `EdgeOnlooker`; sets `SiteFacade`, `PopUp`, `groundMarks` / `GroundMarks`.
- **Mascot**: `Elephant` / `ElephantTimeline` / `hop` (pose pops, no fades; perched idle 0.25 so each look pop reads).

  and a faster exit would strobe.
- "The old emblem's ear droops" is drawn as the emblem sagging further on its cane (+6 deg, outBack) with a falling dust
  speck: the emblem's ear is not a separate part of the props geometry.

  clock); in the film, Film draws it. If S09 renames `TramWiper` / `tramPipAt` / `TRAM`, update the import in
  `Scene10.tsx`.

  wrap overrides here silently stop applying: re-check after set changes.
