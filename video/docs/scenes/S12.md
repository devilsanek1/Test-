# S12 Before there was even a fix: the rewind (scene notes)

"And some of those governments did it before there was even a fix." (w165-w177). Film 52.163-55.36 s (3.197 s, 96
frames): cut(everything) -> END, the closing beat at PEAK-1 framing and the LOOP. Files: `src/scenes/Scene12.tsx`
(World + the shot), `src/scenes/scene12/`: `plaza.tsx` (the shot: S01's plaza layer by layer on S12's camera and the
S01 clock), `timing.ts` (word starts, beats, the S01 clock W(t) and the tape step table), `cast.tsx` (the P / R plans,
Pip's landing, Bit's walk home, S11's sticky note, the P-phase edge onlooker), `camera.ts` (the one pull-back),
`entry.tsx` (isolated preview entry: S12, S12nc, S01nc, S11nc).

## How it is built: S01's own code on an "S01 clock"

S12 is S01's plaza (scene01/plaza.tsx `PlazaShutdown`, mirrored layer by layer: the same GovernmentPlaza props
(`state="frame0"`, S01_GOV minus the hardware, S01_WINDOWS, civic / lantern switches), S01Shutter x3, the dome
LanternOff, DoorLanterns, PlazaCitizen, Pigeon, PipS01, NearObserver, Onlookers, TreeTicks, S01Branch, and the sun:
SunPress `release` + Sun + S01Glyph + SunRipple + PressTicks), rendered inside a `TimeProvider` whose clock is an S01
time W(t) (`timing.ts s01Clock`):

- **P phase** (cut -> 'before', 0-1.547 local): W = 4.45 + t runs FORWARD in S01's settled tail (every S01 event,
  the onlooker's phone and Pip's look-back included, is done by 4.45 s; the lock ring and the leap to S02 are not
  drawn). The plaza sits exactly in the state S01 left, its idle life runs (bobs, tree / branch sway, pigeons, Bit),
  and S12's own beats are extra events in the same clock (`P_*` plans in cast.tsx).
- **R phase** ('before' -> END): W runs BACKWARDS through S01 as a TAPE: one S01 time per 12-fps step (each pose held
  2-3 frames), each step a readable pose of a reversed S01 beat on its S12 word (`R_STEPS`, written through S01's own
  beat table, so a retimed S01 keeps the rewind in step). 17 steps (fix round 2: was 18; fix round 1: was 19); it
  reaches W = 0 = S01's frame 0 at 2.880 local (first drawn f87, film 55.063) and holds 9 frames to the seam. Pip's
  reversed startle hop runs on his own 3-pose tape (`PIP_R_STEPS`, from 'there'); the crossbar pigeons and the front
  walker fC run on their own tapes too (fix round 3: `PIGEON_R_STEPS` from 'even', `WALKER_R_STEPS` from 'a'), so
  their reversed beats land on their storyboard words.
  R-phase plans = S01's own, minus what S12 does not replay (`R_*`): the pigeons' scatter / circle-back (they stay on
  the bar until their landing plays backwards), the padlock glints, Pip's exit to S02; govB's dome lantern switch moves
  to `DOME_LANTERN_R` = 2.97 so the rewind relights it on 'there' WITH Pip's reversed hop (step 4), one step before the
  lamp (storyboard order; frame 0 unaffected). S12-only offsets that never reach frame 0: govB's padlock 10 left (442),
  the two 'those' pigeons perched at x 124 / 154 (S01: 118 / 148).
- On S12's own smooth clock: the camera, the glyph swaps, Bit (on govB's shackle, then his walk home on his own
  reversed clock, 0 on arrival), S11's note (its own clock, stepped with the tape), the 'did' sparkles, sB's point arm.
- On Pip's own stepped clock (`pipClockR`): S01's tape, except 3 hop poses at 12 fps from 'there' - 0.02.
- On their own stepped clocks (fix round 3, `ownTape` in timing.ts: 12 fps steps, then the shared tape clamped to the
  last step, so both reach W 0 with everything else): the crossbar pigeons (`pigeonClockR`: W 0.85 / 0.5 / 0.2 / 0.02
  from 'even' - 0.02, f67-f77) and the front walker fC (`walkerClockR`: W 0.30 / 0.15 / 0.02 from 'a' - 0.02, f72-f79).

**The seam: the last frame IS frame 0, 0 px.** `S12nc` at 3.1667 (= film 55.333, the last frame) vs `S01nc` at 0,
full scale, no captions: **0 pixels differ** (checked after every change; scratchpad seam2/). The camera lands one
frame early (`CAM.t1` = END - 0.03) so the last frame is exactly at rest with ~0 velocity; W = 0, Bit's clock 0, the
glyph handed back to S01Glyph after its pop settled. KEEP IN STEP WITH scene01/plaza.tsx `PlazaShutdown`: if S01
adds / removes a layer extra, mirror it in plaza.tsx (the 0 px check catches it).

Why not `plazaShutdownGov(at, S01_GOV)` (orchestrator note): it re-times S01's spec onto the SET's own shutter /
padlock / tag rigs, but S01 draws that hardware scene-side (scene01/shims `S01Shutter`: the big cream padlocks, the
lock-click jolt, govC's partial-drop jolt, TagString), so the set rigs would not match S01's look. S12 instead passes
S01_GOV itself (lettered tags, S01's rail offsets) through S01's own components under the S01 clock: the opening
state is S01's last state and the end is S01's frame 0 by construction, whatever S01 tunes.
