## Upload checklist (every video, every platform)

- **Instagram:** Settings and activity → Data usage and media quality → **Upload at highest quality** ON; data saver
  OFF; upload on strong Wi-Fi. Post the file as-is: no in-app filters or edits. Judge quality after ~10-15 min (it
  sharpens once processing finishes).
- **TikTok:** on the Post screen → More options → **Allow high-quality uploads** ON.
- **YouTube Shorts:** upload a **1440x2560** master. YouTube gives uploads above 1080p its better VP9/AV1 encodes, and
  our film is vector, so the bigger render is genuinely sharper.
- **Getting the file to the phone:** download the original (AirDrop, Files, Drive). Never send it through
  WhatsApp/Messenger, which recompress it.
- **Upload each platform natively, from the clean file.** Never repost a TikTok download (with the watermark) to Reels or
  Shorts: Instagram says it doesn't recommend Reels that are visibly recycled from other apps.
- **Our export:** 1080x1920, 60 fps since v3 (playbook Motion; v1 was 30 fps), H.264 High, SDR BT.709 tv-range, AAC 48 kHz, ~10-12 Mbps or CRF 14, +faststart.
  4K doesn't help on Reels.

## Linking the accounts

- **TikTok → Instagram:** TikTok Edit profile → social links → add Instagram. It shows an icon on the TikTok profile.
  It may need a Business/Creator account, and some reports say 1,000+ followers.
- **Instagram → TikTok:** Instagram Edit profile → Links → Add external link → `https://www.tiktok.com/@<handle>`.
- **YouTube:** channel → Customize → Links, add both.
- **Cross-posting:** there's no native Instagram ↔ TikTok auto-post that keeps quality. Upload natively to each, or use a
  scheduler (e.g. Buffer, Later, Metricool) that posts the original file to all three.
