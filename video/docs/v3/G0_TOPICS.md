## AI is outbidding you for the memory in your laptop

**Big question.** Is AI going to make my everyday life more expensive?

**So-what chain.** PC shipments fell about 21% in a quarter, so what? Makers raised prices because memory chips cost about 5x more.
So what? Memory makers are moving factory lines to the high-end memory AI data centres buy, because those buyers pay more.
So what? Less ordinary memory is left for laptops and phones, and memory and storage are now about 40% of what a PC costs to build
(about 15% normally). So what? Computers, which almost always got cheaper, cost about 10% more than a year ago (US CPI). Someone
replacing a dead laptop this Christmas pays more or gets less, and analysts don't expect relief before 2027-28.

**Understanding shift.**
- Before: "Laptops seem pricier. Inflation, I guess."
- During: "Wait, computers went *up*? And it's because of AI?"
- After: "There's an auction for memory chips, and data centres outbid me without me knowing I was bidding."
- Tell-a-friend version: "AI data centres are buying up the memory chips, so laptops got pricier this year for the first time in ages."

**Uncertain or disputed.**
