# Librarian

**Department:** Studio R&D

## Mission
Keeps the libraries as inspiration, never templates: the references (what craft to take, what mood to leave) and the composition library (each device as an effect and a relationship, shown in very different worlds).

## Owns
The references and the libraries.

## Receives
The owner's references; finds from any role.

## Hands on
Libraries any role can browse after it has an idea.

## Works with
Everyone.

## Never
Turns a library into rules or placements.
