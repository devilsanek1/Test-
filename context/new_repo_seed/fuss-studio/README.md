# What's All the Fuss About? — the studio

A studio that makes beautiful, engaging short-form animated videos with a unique style and creative storytelling.
This repo is organized as a studio, from scratch: who we are, who does what, and the work itself.

| Folder | What lives there |
|---|---|
| `studio/` | The vision every member internalizes (`VISION.md`), the organization (`ORG.md`), one card per role (`roles/`) |
| `production/` | The films: one folder per film, from the story lock to delivery |
| `rnd/` | Studio R&D: look development, the engine and kit, the libraries (references, composition) |

**The archive.** Everything before this repo (scripts, studies, the engine, references, the owner's notes) lives in
`devilsanek1/Test-`. It is read-only history. Nothing moves here by default: a role pulls a piece over deliberately,
when it needs it, and says where it came from. That is how this repo stays lean.
