# Production

One folder per film in `films/` (e.g. `films/01-helsinki-heat/`), holding the film's work in the order it is made:
the story lock, the vision note, the arc pitches, the board-o-matic, the animatic, the final. The film creative
director keeps the film's folder and its one-page status. The step-by-step flow is in `../studio/ORG.md`.
